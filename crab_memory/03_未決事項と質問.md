# 未決事項と質問

## 決定記録（2026-09-18 回答済み）

| # | 質問 | 回答 | 設計への影響 |
|---|---|---|---|
| Q1 | 最初の対象文章 | **論説文** | 関係型は主張・根拠系を優先。小説向けの出来事・人物ノードは後回し |
| Q2 | 利用者 | **開発者2人（自分たち用）** | UI は最小限。設定（API キー等）は各自がブラウザに保持でよい |
| Q3 | 文章の長さ | **数百〜数千字** | 分割処理・非同期処理は不要。1文章＝1回の処理で済む |
| Q4 | 図の目的 | **俯瞰が主。追跡も必須** | 全体図（議論マップ）を主画面にし、本文パネルとの相互ハイライトで追跡を担保 |
| Q5 | 動作環境 | **Web。言語は問わない** | ブラウザだけで完結する静的 Web アプリにする（→ 04） |
| Q6 | 外部 AI API | **利用可。ただし費用はかけたくない** | サーバーを持たない。AI 層は差し替え可能にし、ルールのみ版を先に作る（→ 02 §5） |
| Q7 | 手動修正 | **デバッグ機能として含める** | 修正結果を JSON で保存・書き出しできるようにし、評価データにも流用する |
| Q8 | 「動き」の意図 | **動きを見せたい方に近い** | 動詞ごとのアニメではなく、関係型ごとの動き（押す・支える・反転する）で表す（→ 01 §5.1） |
| Q9 | 画像出力 | **静止画は必要。動きは対象外** | SVG で描画し、SVG / PNG に書き出す。アニメはブラウザ内のみ |
| Q10 | 対象言語 | **日本語のみ** | 文分割・接続表現辞書は日本語専用でよい |
