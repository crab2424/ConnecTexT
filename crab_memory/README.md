## 現時点の結論（詳細は各ファイル）

決定済み（2026-09-18 の回答に基づく）:

- **対象**: 日本語の論説文、数百〜数千字。利用者は開発者 2 人。
- **中核**: 文（命題）ノード＋関係エッジの中間表現（JSON）。図はそこから機械的に描く。
- **図**: 俯瞰用の議論マップ（階層レイアウト）を主画面に、本文パネルとの相互ハイライトとステップ再生で追跡を担保。
  静止画は SVG / PNG で書き出す。
- **動き**: 動詞ごとのアニメではなく、関係型ごとの動きのメタファー（押す・支える・反転）で表す。
- **AI**: 使う。ただし費用は完全ゼロで進めるため、ルールのみ版（段階0）→ ブラウザ内 LLM（段階1）の順に作る。外部 API はアダプタの口だけ残し、有料化は必要になったら再検討。
- **環境**: サーバーを持たない静的 Web アプリ。TypeScript + Vite + React、SVG 描画。GitHub Pages で無料ホスティング。
- **手動修正**: デバッグ機能として含め、修正結果を JSON に保存する。

次の段階: 05 の関係型と中間表現スキーマのレビュー → サンプル文章の正解付け → 雛形作成と段階0 の実装。
