# crab_memory — 設計検討メモの索引

文章の論理構成を可視化するアプリ（ConnecTexT）の、実装前の検討メモ置き場。
ここは「決めたこと」「まだ決めていないこと」「なぜそう考えたか」を残す場所で、
コードや仕様書ではない。方針が変わったら該当ファイルを書き換える（履歴は git に残る）。

## 現時点の仮の結論（詳細は各ファイル）

- **何をするか**: 文章 → 「文（命題）ノード＋関係エッジ」の中間表現（JSON） → 図。
  図は静止画（縦フロー）を基本に、読み順に図が育つ「ステップ再生」で時間軸を入れる。
  動詞のアニメーション化は「内容」の可視化であり「論理展開」の可視化とは別問題なので、初期スコープから外す。
- **AIを使うか**: 使う。ただし文分割・接続表現検出はルール、関係の確定と要約はAI、
  描画はプログラム、という分業にする。AIの出力は固定スキーマのJSONに限定する。
- **最初のデモ対象**: 論説文・説明文（500〜2000字）。小説は第2段階（要確認）。
